# 简历生成器 - 设计文档

**日期**: 2026-06-04  
**状态**: 设计完成，待用户确认

## 概述

纯前端单页应用，用户填写表单后实时预览简历，支持导出 HTML 和 PDF。零依赖，一个 HTML 文件包含全部 CSS 和 JS。

## 页面布局

左右分栏：
- **左侧**：标签页表单，包含多个信息区块
- **右侧**：实时预览面板，反映当前表单数据

## 表单字段

**基本信息**
- 姓名（文本）
- 头像（图片上传，存储为 Base64）
- 意向岗位（文本）
- 职位方向（文本）
- 电话（文本）
- 邮箱（文本）

**教育背景**
- 学校名称、专业、学院、GPA、起止时间、主修课程

**技能**
- 动态标签列表，用户可添加/删除，不限数量

**项目经历**
- 每个项目：名称、角色、起止时间、项目类型、团队规模、描述要点（可增减）
- 支持多个项目，可动态添加/删除

**竞赛荣誉**
- 动态条目列表，可添加/删除

**证书**
- 动态条目列表，可添加/删除

**自我评价**
- 多行文本

## 功能特性

1. **3 种模板风格可选**：现代商务风（默认）、经典正式风、极简轻量风。切换时实时预览更新
2. **自动保存**：表单数据实时存入 localStorage，关浏览器不丢失
3. **头像**：上传后转为 Base64 嵌入，预览区顶部横幅展示
4. **实时预览**：右侧面板随表单输入即时刷新
5. **导出 HTML**：将当前预览内容下载为独立 HTML 文件，包含内嵌样式，可直接打印或发送
6. **导出 PDF**：通过浏览器打印对话框，用户选择"另存为 PDF"，利用 `@media print` 优化打印样式

## 技术方案

- 单个 HTML 文件，无框架，无构建工具
- 纯 JavaScript 处理表单状态、模板渲染、localStorage、导出
- CSS 变量控制三套模板的主题色切换
- `@media print` 隐藏表单区，仅输出简历内容
- 头像使用 FileReader API 转 Base64 存储
