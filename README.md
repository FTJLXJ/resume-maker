# 简历生成器

一个纯前端的在线简历制作工具，无需注册，打开即用。

**在线使用**：https://ftjlxj.github.io/resume-maker/简历生成器.html

## 功能

- 表单填写，右侧实时预览简历效果
- 3 种简历模板可选切换（现代商务 / 经典正式 / 极简轻量）
- 智能解析：粘贴经历文字或上传 Word 文件，自动填入表单
- 导出为 HTML 文件或 PDF
- 数据自动保存在浏览器本地，关闭不丢失
- 零依赖，单个 HTML 文件即可运行

## 本地使用

下载 `简历生成器.html`，双击在浏览器中打开即可。

## 反馈

使用中遇到问题，可在 [Issues](https://github.com/FTJLXJ/resume-maker/issues) 页面提交，或通过导出后弹出的反馈窗口发送。
